# 🌐 Web Ripper & Website Downloader (Parsing-Photo)

[Uzbekistan] Мощный асинхронный скрипт на Python для полного копирования (дампа) веб-сайтов. Он перехватывает абсолютно все сетевые запросы при загрузке страницы и сохраняет на диск полную локальную копию сайта: HTML, CSS, JavaScript, изображения, шрифты и медиафайлы, полностью сохраняя оригинальную структуру папок на сервере.

Скрипт оптимизирован для работы с современными SPA-сайтами, интерактивными онлайн-приглашениями (taklifnomalar) и галереями, где контент подгружается динамически через JavaScript или Lazy-Load.

---

## ✨ Особенности / Xususiyatlari

- **Полный Дамп (Full Site Copy):** Скачивает не только картинки, но и стили (`.css`), скрипты (`.js`), шрифты (`.woff`, `.ttf`), аудиофайлы и структуру страниц.
- **Обход Dynamic JS & Lazy-Load:** Благодаря интеграции с Playwright, скрипт автоматически прокручивает страницу до самого низа и имитирует действия реального пользователя, заставляя прогрузиться скрытые элементы.
- **Умная фильтрация:** Скачивает файлы только с целевого домена. Весь сторонний мусор (внешняя реклама, счетчики Яндекс.Метрики, Google Analytics) автоматически игнорируется, не забивая ваш диск.
- **Windows-совместимость:** Автоматически очищает имена файлов от запрещенных операционной системой символов (`\ / : * ? " < > |`).
- **Визуальный прогресс:** Красивые интерактивные статус-бары (`tqdm`) для контроля процесса скачивания в реальном времени.
- **Поддержка Python 3.14+:** Полная совместимость с самыми свежими версиями Python благодаря современной асинхронной архитектуре.

## 🚀 Инструкция по установке / O'rnatish ko'rsatmalari

### 1. Клонирование репозитория (Repositoryni yuklab olish)
Откройте терминал/командную строку и выполните:
```bash
git clone https://github.com/AnonimusShamshiAlex/parsing-site
cd parsing-site
```

### 2. Установка зависимостей (Kutubxonalarni o'rnatish)
Установите необходимые библиотеки с помощью утилиты `pip`:
```bash
pip install playwright tqdm requests
```

### 3. Инициализация системных браузеров (Brauzerlarni yuklash)
Загрузите необходимые бинарные файлы браузеров для движка Playwright:
```bash
python -m playwright install
```

## 💻 Использование / Foydalanish

Для запуска процесса полного копирования сайта передайте URL-адрес целевой страницы в качестве аргумента:

```bash
python parsingsite.py http://google.com
```

### Дополнительные параметры (Katalog parametrini sozlash)
По умолчанию скрипт создаст папку с именем домена сайта прямо в директории проекта. Если вы хотите задать другое имя папки или путь для сохранения, используйте флаг `-p` или `--path`:

```bash
python parsingsite.py http://google.com -p "C:\MyWebsites\WeddingSite"
```
